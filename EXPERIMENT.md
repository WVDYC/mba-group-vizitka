# Эксперимент: смета нескольких единиц техники

Исходная версия сохранена в GitHub как тег `v1-photo-baseline`, коммит `7cb3e7a91ed930d2c298a5170a0c673bb5c7c7a3`. Публикация Sites №1 также содержит исходную версию. Основная ветка GitHub остаётся исходной; эксперимент находится в `experiment/multi-equipment-calculator`.

Калькулятор теперь собирает смету: несколько типов техники, количество машин и индивидуальный срок аренды для каждой строки. Месячные и суточные тарифы сохраняют свои единицы. Сумма строки = тариф × количество × срок. Неизвестные цены выделяются отдельно от известной части сметы. Стоимость подачи и НДС не добавляются автоматически — их уточняет менеджер.

Из каталога можно добавлять позиции кнопкой «В расчёт». Повторное добавление увеличивает количество существующей строки. Можно удалять строки, включая все позиции. Смета сохраняется в localStorage этого браузера. WhatsApp получает список, количества, сроки, суммы строк и известный итог; фактическая отправка остаётся за посетителем.

Проверка расчётов: `node --test tests/estimate.test.mjs`. Покрыты смешанные сроки, несколько машин, неизвестные цены, пустой состав и недопустимые значения. Пример: кран на месяц + 2 погрузчика на 2 месяца + компрессор на 3 дня = 14 010 000 ₸.

Для возврата к исходной версии можно опубликовать сохранённую версию Sites №1 либо собрать исходники по тегу `v1-photo-baseline`. Удалять историю и делать force-push для этого не требуется.
