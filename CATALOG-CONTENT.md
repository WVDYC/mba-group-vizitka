# Подробные описания каталога

У всех 8 позиций есть короткое описание, раскрывающиеся характеристики, примеры задач и сведения для заявки. Числовые параметры семи исходных позиций взяты из первоначального каталога MBA Group: https://rad-halva-3cc273.netlify.app.

Дополнительно подтверждены только сведения о CS-4000 из предоставленного документа, фотографии и голосового владельца, а справочные параметры серии — по странице производителя. Подробности и расхождения записаны в SPIDER-CS4000.md.

Марка погрузчиков, длина стрелы Zoomlion, модификация CAT 330, объём его ковша, нагрузка люлек, боковой вылет автовышек, давление и производительность компрессора не придуманы: эти поля вынесены на уточнение менеджером. Для CS-4000 грузовой режим и режим люльки описаны отдельно.

Цены, периоды расчёта и идентификаторы существующих позиций сохранены. Сметы в браузере продолжают использовать те же позиции с обновлёнными названиями и фотографией мини-крана.
